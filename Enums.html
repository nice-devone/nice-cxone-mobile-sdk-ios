  • ContactHandler

    The party currently responsible for handling a contact.

    A contact starts out held by whichever party the channel is configured to engage first. While an automated bot holds it, the customer is not queued for a human agent - there is no position in queue to report. Once the bot hands the conversation over, the handler becomes cxone and the regular routing rules apply again.

    The platform only reports a handler on channels where the capability is enabled, which is why contactHandler is optional.

    See more

    Swift

    public enum ContactHandler : String, Equatable, Sendable

  • ChatState

    State of the chat

    Here is a table of states with their basic description. Those states are internally handled by the SDK based on its usage.

    State Description
    initial Initial state of the SDK
    preparing The SDK is preparing for usage
    prepared The SDK has been prepared for basic usage = unable to use chat features!.
    offline Channel currently unavailable (only for live chat channel configuration).
    connecting Socket connection is establishing for chat usage
    connected Socket connection has been established
    ready Chat is ready to use based on it’s configuration status
    closed An agent or customer has closed the thread
    See more

    Declaration

    Swift

    public enum ChatState : Comparable, Sendable
  • ChatThreadState

    Enum representing the possible states of a chat thread.

    State Description
    pending Thread has been created locally.
    received Thread has been received from the server (not yet loaded).
    loaded Thread has been loaded (not yet recovered).
    ready Thread has been prepared to use (loaded metadata and recovered all messages).
    closed Thread has been archived or closed.

    Each case corresponds to a specific state of the chat thread, providing clarity on its current status.

    See more

    Declaration

    Swift

    public enum ChatThreadState : Comparable, Sendable
