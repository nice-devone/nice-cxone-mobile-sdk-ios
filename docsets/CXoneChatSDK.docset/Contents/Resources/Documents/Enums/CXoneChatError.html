CXoneChatError

public enum CXoneChatError : LocalizedError, Equatable

The different types of errors that may be experienced.

Errors when calling any method

  • featureUnavailable(_:)

    The feature is not currently available for use.

    This error indicates that a feature the SDK supports could not be used because the SDK has deliberately disabled it in the current release. The associated value carries the human-readable feature name so it can be surfaced in integrator-facing error messaging and logs.

    • Source of problem: The feature is intentionally disabled in the current SDK version.

    Attention

    Wait for a new release of the SDK.

    Declaration

    Swift

    case featureUnavailable(String)
  • sdkVersionNotSupported

    The SDK version being used is no longer supported.

    This error occurs when the SDK version is outdated and incompatible with the current API.

    • Source of problem: Deprecated SDK version.

    Attention

    Please upgrade to the latest version of the SDK to ensure compatibility and access to all features.

    Declaration

    Swift

    case sdkVersionNotSupported
  • notConnected

    An attempt was made to use a method without connecting first.

    Most of the methods in the SDK require a connection to CXone services.

    • Source of problem: SDK used incorrectly.

      Attention

      Make sure you call connect() or connect() method first.

    Some features are available only with multithread channel configuration.

Errors when using transaction token authentication

  • transactionTokenRequestFailed(statusCode:)

    The transaction token request failed.

    This error occurs when the SDK is unable to obtain a transaction token from the server. The token is required for WebSocket authentication when using secured cookie or third-party OAuth authentication modes.

    • Source of problem: Network issue/Server issue/SDK issue

    Attention

    Check network connectivity and ensure the channel is properly configured for transaction token authentication. Otherwise, gather any information about how the error was encountered and contact the CXoneChat SDK team.

    Declaration

    Swift

    case transactionTokenRequestFailed(statusCode: Int)

    Parameters

    statusCode

    The HTTP status code returned by the server.

Errors related to OAuth token handling

  • invalidAccessToken

    The provided access token is invalid.

    This error occurs when the token supplied via setConnectionToken(_:expiresAt:) is empty, expired, or rejected by the backend.

    • Source of problem: SDK used incorrectly / OAuth provider issue

    Attention

    Obtain a fresh token from your OAuth provider and supply it to the SDK.

    Declaration

    Swift

    case invalidAccessToken
  • invalidRefreshToken(_:)

    The session’s refresh token could not be used to recover the session automatically — it was rejected by the backend, was never stored, or the refresh grant returned no new access token.

    This error occurs when a refresh-grant recovery attempt for the explicit OAuth flow cannot succeed and no further automatic recovery is possible.

    • Source of problem: OAuth provider issue / refresh token revoked or expired

    Attention

    The app owns re-authentication in this case — perform a new authorization-code (PKCE) grant to obtain a fresh access + refresh token pair, then supply it to the SDK.

    Declaration

    Swift

    case invalidRefreshToken(String?)

    Parameters

    message

    The backend’s own description of the rejection, when it supplied one. It is a fixed string tied to the backend’s error code rather than text from the OAuth provider, so it is useful for diagnostics and logging but should not be parsed or branched on. nil when the session could not be recovered without the backend rejecting anything — no refresh token was stored, or a successful response arrived without a new access token.
