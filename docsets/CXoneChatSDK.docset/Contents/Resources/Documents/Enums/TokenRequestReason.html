TokenRequestReason

public enum TokenRequestReason : Sendable, Equatable

The reason the SDK is requesting a fresh connection token from the integrator.

Passed to the listener registered via setTokenDelegateListener(_:) so integrators can log or branch on the context (e.g. silent refresh vs. full re-login). Implementations are free to ignore the reason and always perform the same token-fetch action.

  • tokenExpired

    The current token expired (or is about to) — the SDK requests a fresh one before it becomes unusable.

    Declaration

    Swift

    case tokenExpired
  • tokenInvalid

    The backend rejected the token at connect time (HTTP 400); a fresh one is required to establish the session.

    Declaration

    Swift

    case tokenInvalid
