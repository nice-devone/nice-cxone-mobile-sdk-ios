  • CXoneChat

    Entry point of the CXone Chat SDK and the canonical conformer of ChatProvider.

    Construct one CXoneChat instance at app start with init() and hold the reference for the lifetime of your chat experience. Pass it through your app as the protocol type ChatProvider to keep code testable. Use the provider properties (connection, customer, threads, analytics, customerCustomFields, proactiveAction) to drive the SDK; subscribe to events() for state changes, thread updates, and errors.

    CXoneChat is @MainActor-isolated — call sites from background contexts must hop to the main actor (see the ChatProvider protocol docs and the Migration Guide for details).

    Important

    Earlier SDK versions exposed CXoneChat.shared and CXoneChatDelegate. Both are removed. See migration-from-singleton.md for the upgrade walkthrough.
